# GEANT4 v11.4.2

This Dockerfile creates an image based on debian which has Geant4 v11.4.2 
installed. This is intended to work with a TOPAS installation.
See [the TOPAS docs](https://github.com/OpenTOPAS/OpenTOPAS/blob/main/OpenTOPAS_quickStart_Debian.md) for more information about the structure
of the image and how Geant4 is installed.
